# Medical Mod

Realistický zdravotnický systém pro Minecraft Forge 1.20.1.

## Základ projektu

- Minecraft: 1.20.1
- Forge: 47.x
- Java: 17
- Mod ID: `medicalmod`
- Java package: `cz.vasek.medicalmod`

## Plán první verze

- zdravotní data hráče
- krvácení
- bolest
- bezvědomí
- obvaz a škrtidlo
- vyšetření pacienta
- synchronizace serveru a klienta

## Vývoj

Projekt je určený pro IntelliJ IDEA a používá Gradle wrapper dodaný s Forge MDK.
